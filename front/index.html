About this project

Book Catalog

Purpose
A university project: a small online library where readers find, borrow and review books.
Subject area
Library: books, authors, publishers, genres, members, librarians, loans, reservations and reviews.
Database
PostgreSQL on Supabase, 11 tables, with stored functions and a separate application role.
Built with
Django (JSON API and admin), HTML, Bootstrap and vanilla JavaScript.

Main functions

  • Catalog and search by title, author, genre, year and rating
  • Accounts: register, sign in, profile
  • Borrowing and reservations
  • Reviews and ratings
  • Administration panel for all library data
